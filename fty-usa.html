❓ FTY Scanner — Quick Guide

New here? Follow these 3 steps — that's it.
1
Hit Scan MarketTop USDT coins on Binance are scanned automatically. First time, keep Top 100 (~40 sec) — Top 300 takes ~3 minutes.
2
Pick what to scan — then filter what you seeSCAN SCOPE = what the scan covers: All TFs, ⚡ this TF only (much faster) or Pick TFs for a custom set. MODE = AUTO or one fixed EMA (50/100/200… quicker still). TIMEFRAME just switches the results board · FILTERS = Strong Buy / Fresh Setup.
3
Open a coin, check the chart, track itClick a row = mini chart + checks · Full Chart = drawing tools, indicators, replay · ★ = watchlist · ৳ = paper trading (no real orders).
📊 TABLE KE COLUMNS
  • Score — 0–100: how many times price respected the EMA
  • Never Broke — bounce count on EMA retests (higher = stronger)
  • Distance — how far price is from the EMA in % (small = fresh entry zone)
  • Setup — candle patterns: Hammer, Pin Bar, Bullish…
  • Signal — STRONG BUY, the highest-confidence combo
⌨️ KEYBOARD
  • 1 Scan · 2 Chart · 3 Results
  • s scan start/stop · / search coin
  • c copy next 30 · k cards/table view
  • ⌘K command palette · Esc to close
📈 WHAT'S IN THE CHART
  • Scroll / pinch = zoom · drag = pan (left-right + up-down)
  • Drawings: trend, ray, fib, zone, text… (click points)
  • Right-click drawing = delete · Ctrl+Z undo
  • Replay = bar-by-bar practice (Space play)
  • Vol / RSI / MACD / BB — toggle from the toolbar chips
Paper trading — practice only, no real orders · live prices from Binance
